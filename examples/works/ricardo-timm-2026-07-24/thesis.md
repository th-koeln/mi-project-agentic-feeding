Animationen geben Benutzeroberflächen nicht nur Bewegung – sie vermitteln auch Bedeutung. Doch warum signalisiert eine bestimmte Bewegung eigentlich einen Zustandswechsel, eine Bestätigung oder eine Benachrichtigung?

Diese Abschlussarbeit entwickelt mit dem Semantic Motion Framework ein regelbasiertes System, das die Bedeutung von UI-Animationen theoretisch begründet. Dafür verbindet sie Ansätze aus Semiotik, Wahrnehmungspsychologie und Motion Design. Ein prototypischer Semantic Motion Editor macht das Framework praktisch nutzbar: Animationen können ausgewählt, begründet und direkt ausprobiert sowie als Code exportiert werden.

So entsteht ein Ansatz, der UI-Animationen nicht nur gestaltet, sondern auch erklärt, warum sie so funktionieren, wie sie funktionieren.
